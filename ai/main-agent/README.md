# Главный агент — MVP

Первая программная оболочка Главного агента проекта «Управление автопарком».

## Что уже есть

- системная инструкция агента;
- список техники в тестовой памяти;
- `get_fleet()`;
- `get_vehicle()`;
- `get_vehicle_history()`;
- `get_repairs()`;
- `get_attention_items()`;
- `create_repair()`;
- простейшее определение техники по госномеру, VIN, марке или модели;
- тестовый маршрутизатор запросов.

## Что пока временное

Данные хранятся в памяти Python и исчезают после перезапуска. Реальная база данных и LLM ещё не подключены.

## Следующий этап

1. Подключить реальные данные автопарка.
2. Добавить таблицы/Backend API.
3. Подключить LLM tool calling вместо простого маршрутизатора.
4. Добавить расчёт `get_attention_items()`.
5. После этого подключить чат интерфейса.

## Запуск

```bash
python main_agent.py
```
