# Главный агент — контур автопарка

Главный агент экосистемы организации. Первый подключенный домен — приложение «Управление автопарком».

## Архитектура

`MainAgent -> FleetConnector -> HttpFleetBackend -> fleet-management API -> PostgreSQL`

Главный агент не получает прямой доступ к базе автопарка. Связь выполняется сервис-сервис через защищенный API приложения автопарка.

## Реализовано

- определение техники по госномеру, VIN, марке или модели;
- список и карточка техники;
- история;
- ремонты;
- ТО;
- документы, ДК, ОСАГО и московские пропуска;
- топливо;
- установленные запчасти;
- закупки;
- сводка по автомобилю;
- контроль элементов, требующих внимания;
- `HttpFleetBackend` для реального приложения автопарка;
- production-сборка в `runtime.py`.

## Подключение

В окружении Главного агента:

```env
FLEET_API_BASE_URL="http://localhost:3000"
FLEET_MAIN_AGENT_API_KEY="<secret>"
```

В окружении `fleet-management` должен быть установлен тот же секрет как `MAIN_AGENT_API_KEY`.

Секреты не хранятся в GitHub.

## Ограничения текущего этапа

Чтение реальных данных подключено архитектурно. Запись ремонтов через сервисный API пока намеренно не включена: операции изменения данных будут добавляться отдельно с аудитом и разграничением прав.

Следующие приложения экосистемы (финансы и планирование, продажи и маркетинг и другие) подключаются к Главному агенту отдельными коннекторами, без смешивания их баз данных.
