# Security contracts

Этот каталог хранит только архитектурные контракты взаимодействия Главного агента с отдельным контуром безопасности.

Главный агент:
- знает, что внешний контур безопасности существует;
- может читать только публичный статус безопасности, если это будет разрешено;
- НЕ имеет инструментов блокировки, удаления, резервного копирования или уничтожения данных;
- НЕ содержит секретов, ключей или административных команд Security Control.

Все опасные операции выполняются исключительно отдельным приложением Security Control с отдельной авторизацией.
