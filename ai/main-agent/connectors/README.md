# Коннекторы Главного агента

На текущем этапе реально подключается только приложение «Управление автопарком».

## FleetConnector

`fleet_connector.py` задаёт единый контракт между Главным агентом и backend автопарка.

Главный принцип: Главный агент не ходит напрямую в таблицы базы данных. Он работает только через методы коннектора.

Первая версия поддерживает:

- список техники;
- карточку техники;
- историю техники;
- ремонты;
- создание ремонта;
- события, требующие внимания.

Каждый ответ оборачивается метаданными `source_system`, `source_record_id`, `record_type`, `payload`. Это подготовка к будущей экосистеме, где позже появятся отдельные коннекторы к приложениям «Финансы и планирование» и «Продажи и маркетинг».
