# Финансовое ядро Главного агента

## Версия 0.1 — банковские операции

Банковская выписка является основным источником фактического движения денежных средств, но банковский платёж не считается автоматически фактическим расходом конкретного автомобиля.

### Принципы

1. Исходная банковская операция после импорта не изменяется классификатором.
2. Классификация хранится отдельно от исходной операции.
3. Неуверенные операции получают статус `needs_review` — «Требует проверки».
4. Оплата поставщику может быть авансом и позже связываться с фактическими хозяйственными операциями.
5. Экономика автомобиля строится по связанным данным из банка, топлива, ремонтов, закупок и других модулей, а не только по выписке.

### Реализовано

- импорт банковских операций;
- защита от повторного импорта по `transaction_id`;
- приход/расход;
- первичная классификация по назначению платежа и контрагенту;
- оценка уверенности;
- очередь «Требует проверки»;
- неизменяемая модель исходной операции.

### Следующий шаг

Добавить отдельные сущности:

- контрагенты;
- финансовые статьи;
- распределение одной операции между несколькими статьями/объектами;
- счета;
- связь `платёж ↔ счёт`;
- авансы поставщикам;
- механизм расхождений и сверки.
